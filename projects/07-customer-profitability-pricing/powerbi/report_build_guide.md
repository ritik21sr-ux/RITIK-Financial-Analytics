# Power BI report build guide

1. Load `data/sales_lines.csv` at invoice-product line grain; parse `invoice_date` and `month` as dates.
2. Add Date, Product, Customer, and Segment dimensions before using the starter measures in `measures.dax`.
3. Suggested pages: executive trend, product contribution and discount, customer concentration, and segment economics.
4. Use `customer_profitability.csv` to cross-check a customer-level result and `product_profitability.csv` for a product-level reconciliation.

The `.pbix` is **Coming soon**. The guide and measures are a model blueprint, not a published Power BI report.
